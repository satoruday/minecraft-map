# ぼうけんマップ

マイクラで見つけた場所の座標を登録して、地図にピンを立てるWebアプリ。

- 公開URL: https://satoruday.github.io/minecraft-map/
- ビルド不要の素のHTML / CSS / JS（`index.html` / `style.css` / `app.js`）
- データはブラウザの localStorage（キー `bouken-map-v1`）に保存
- Google スプレッドシートと同期できる（任意）：つなぎかたは [SETUP-SHEETS.md](SETUP-SHEETS.md)、サーバー側は [gas/Code.gs](gas/Code.gs)

このリポジトリは公開です。座標データ以外のURL・合言葉などの秘密情報は入れないこと。
